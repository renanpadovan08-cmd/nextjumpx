HOTFIX - LINK ÚNICO DE AGENDAMENTO

Alteração aplicada:
- A aba Barbeiros não gera mais link individual/alternativo para cada barbeiro.
- O link exibido/compartilhado em Barbeiros agora é o mesmo link público da Dashboard.
- O link único leva para a barbearia, onde o cliente escolhe o barbeiro, serviço, data e horário.
- Barbeiros funcionários também usam o link principal da barbearia ao compartilhar.
- Cache/PWA atualizado para forçar o navegador a baixar a versão nova.

Objetivo:
Evitar que o cliente acesse rotas diferentes de agendamento e garantir que apenas o fluxo público correto seja usado.
