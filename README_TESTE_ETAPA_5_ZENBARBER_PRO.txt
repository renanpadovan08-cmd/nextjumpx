ZENBARBER - TESTE ETAPA 5: ZENBARBER PRO

Base usada:
- ZenBarber_TESTE_ETAPA_4B_WHATSAPP_PRO.zip

Objetivo:
- Transformar a área de Backup em uma área mais profissional de gestão, exportação e auditoria.

Incluído:
1. Menu "Gestão PRO" no lugar de "Backup".
2. Backup JSON mais completo, incluindo unidades e auditoria.
3. Exportação CSV da agenda.
4. Exportação CSV da base de clientes.
5. Painel de saúde da base com pontuação.
6. Auditoria de:
   - conflitos de agenda;
   - agendamentos passados sem baixa;
   - clientes sem telefone para WhatsApp;
   - serviços incompletos;
   - barbeiros sem comissão;
   - barbeiros sem unidade vinculada.
7. Atalhos para corrigir pendências, comissões, unidades e serviços.

Observação:
- Esta etapa não altera banco de dados.
- Não exige SQL novo.
- É segura para Netlify de teste.
