ZenBarber — TESTE ETAPA 6: UX Premium / Produto pronto para vender

Objetivo:
Melhorar a primeira impressão do sistema para demonstração comercial, sem alterar regras críticas de agenda, financeiro ou banco.

Alterações principais:
- Visual geral mais premium com glassmorphism, brilho sutil, cards mais modernos e animações leves.
- Dashboard com hero comercial "ZenBarber PRO • operação ao vivo".
- Ações rápidas no topo: Agenda, Central WhatsApp e Clientes Ausentes.
- Dock rápido com atalhos para Agenda, WhatsApp, Carteira, Recuperar Clientes e Gestão PRO.
- Sidebar com rótulos mais comerciais: Dashboard PRO, Agenda Premium, Central WhatsApp, Clientes ausentes e Gestão PRO.
- Topo fixo no desktop para facilitar navegação durante uso real.
- Melhorias de hover, transições, contraste e responsividade.

Observação:
Esta etapa foi pensada para impacto visual e apresentação para clientes que já usam concorrentes como AppBarber/Gendo. Não muda a estrutura do Supabase nem as regras de conflito de agendamento.
