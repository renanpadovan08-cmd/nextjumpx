HOTFIX - VALOR A RECEBER

Alteração solicitada pelo Carriel:
A antiga opção "Receber com desconto" foi renomeada para "Valor a receber".

Agora o barbeiro informa diretamente o valor final recebido.
Exemplos:
- Serviço original R$ 45,00, cliente ganhou desconto: digita 40.
- Serviço original R$ 45,00, cliente levou trufa de R$ 5,00: digita 50.

O sistema cria um serviço ajustado para esse atendimento e conclui o agendamento usando o valor final informado, garantindo que o faturamento some exatamente o valor real recebido.

Arquivos alterados:
- js/modules/agenda.js
- js/modules/relatorios.js
