HOTFIX - RECEBER COM DESCONTO

Alterações:
- Na finalização do atendimento foi adicionado o botão "Receber com desconto".
- Em Clientes em carteira / Valores pendentes também foi adicionado "Receber com desconto".
- O barbeiro informa livremente o desconto aplicado.
- O sistema confirma:
  valor original, desconto e valor real recebido.
- Somente o valor real recebido entra no faturamento.
- Para não alterar o preço original do serviço/pacote para outros clientes, o sistema cria um serviço interno com o valor líquido recebido e vincula apenas naquele atendimento/cobrança.
