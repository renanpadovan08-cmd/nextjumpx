ZenBarber — ETAPA 1 COMERCIAL

Objetivo desta geração:
Transformar a primeira tela do ZenBarber em uma versão mais comercial para demonstração em barbearias, destacando pontos que geram dinheiro e organização imediata.

Implementado:
1. Menu lateral renomeado de "Histórico clientes" para "Clientes ausentes".
2. Página de Clientes Ausentes abre a lista automaticamente, sem precisar clicar em atualizar.
3. Dashboard Premium agora mostra o indicador "Clientes ausentes".
4. Alertas inteligentes avisam quando existem clientes para recuperar.
5. Ações recomendadas exibem "Recuperar clientes ausentes" com atalho direto.
6. Novo bloco no dashboard: "Clientes para recuperar" com botão de WhatsApp por cliente.
7. Estilo visual premium para a nova área comercial.

Observação:
A lógica usa os atendimentos já concluídos. O sistema pega o último atendimento de cada cliente e identifica quem não voltou há 15/30 dias.
